# Expense Tracker

A Python command-line app to track daily expenses and spending habits.

## Features
- Add expenses with category, description and amount
- View all expenses in a formatted table
- Summary of spending grouped by category
- Data saved locally in JSON so it persists between sessions

## Tech used
Python 3, JSON

## How to run
python expense_tracker.py
